\section{Задание}
Дано регулярное выражение: \[(b^{*}(db^{*}\mid c^{*}(dbdc^{*})^{*}\mid b^{*}cb)b)^{*}\]
По имеющемуся академическому регулярному выражению построить:
\begin{itemize}
\item[---] минимальный ДКА, распознающий его язык (минимальность обосновать таблицей классов эквивалентности).
\item[---] возможно малый НКА, распознающий его язык. Возможно малый переключающийся (с конъюнкцией) КА, распознающий его язык. Частично обосновать таблицами множеств классов эквивалентности.
\item[---] расширенное регулярное выражение, распознающее тот же язык
\end{itemize}

\section{Недетерминированный конечный автомат}
Для исходного регулярного выражения построим автомат Глушкова:
\begin{figure}[H]
\centering
\scalebox{1.2}{\input{img/glushkov.tex}}
\caption{Автомат Глушкова}
\end{figure}
Рассмотрим пары состояний автомата для выявления избыточных. 
Для каждого состояния $q_i$ из пары запишем множество всех его переходов в виде множества пар 
\[
(q_j, \lambda),
\] 
где $q_j$ — конечное состояние перехода, а $\lambda$ — символ, вызывающий этот переход.
\begin{enumerate}
  \itemsep -0.8pt
  \item $d_1$ и $b_2$:
    \begin{gather*}
      d_1 \to \{(2, b), (3, b)\}\\
      b_2 \to \{(2, b), (3, b)\}
    \end{gather*}
  \item $S$ и $b_{11}$:
    \begin{gather*}
      S \to \{(0, b), (1, b), (2, b), (4, c), (5, d), (9, b), (10, c), (12, b)\}\\
      b_{11} \to \{(0, b), (1, b), (2, b), (4, c), (5, d), (9, b), (10, c), (12, b)\}
    \end{gather*}
  \item $c_3$, $d_6$ и $c_7$:
    \begin{gather*}
      c_3 \to \{(4, c), (5, d), (12, b)\}\\
      d_6 \to \{(5, d), (7, c), (12, b)\}\\
      c_7 \to \{(5, d), (8, c), (12, b)\}
    \end{gather*}
\end{enumerate}
Заметим, что они лежат в одном классе эквивалентности. Таким образом, далее минимизируя автомат получаем следующий редуцированный автомат Глушкова.

\section{Расширенное регулярное выражение}
Исходное регулярное выражение: \[(b^{*}(db^{*}\mid c^{*}(dbdc^{*})^{*}\mid b^{*}cb)b)^{*}\]
Рассмотрим $b^{*}$ в скобках с альтернативой. Вынесем $b^{*}$ за скобки и объединим с $b^{*}$ за скобками, далее увидим что $(b^{*}(T\mid \epsilon))^{*}$ эквивалентно $((T\mid \epsilon)b^{*})^{*}$. Получем расширенное регулярное выражение:
\[\hat{}((d\mid c^{*}(dbdc^{*})^{*}\mid cb)b+)^*\$\]
